# 01 · Portfolio personal

Crea tu portfolio personal con **HTML y CSS**. El diseño y el estilo son libres: elige los colores, las tipografías y la distribución que prefieras.

Puedes incluir una presentación sobre ti, tus proyectos, tus habilidades y una forma de contactar contigo.

## Requisitos

- Usar **Flexbox**.
- Usar **CSS Grid**.
- Definir los colores con **variables CSS**.
- Usar **BEM** para nombrar las clases CSS.
- Organizar el CSS por bloques: **cada bloque BEM debe tener su propio fichero CSS**, incluyendo sus elementos y modificadores. Por ejemplo, `header.css`, `hero.css` y `project-card.css`.

**Bonus:** despliega el portfolio en **Vercel** e incluye la URL pública en la pull request de entrega.

## Recursos de apoyo

- [Portfolio de referencia en Figma](https://www.figma.com/design/Ynt4jxiAyLwMKjbX2KDEdj/Alex-Moreno-%C2%B7-Tres-portfolios?node-id=0-1): puedes seguirlo como base o crear tu propio diseño.
- [CSS Layout Lab](https://css-layout-pepeloper.vercel.app/): herramienta interactiva para entender y practicar cómo funcionan **Flexbox y Grid**.

## Entrega

Guarda los archivos de tu portfolio en `ALUMNOS/NOMBRE_APELLIDOS/PORTFOLIO/` y abre una pull request siguiendo las [indicaciones del repositorio](../README.md#entregas).
