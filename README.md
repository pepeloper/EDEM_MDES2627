# EDEM · MDES 2026–2027

Repositorio común para las prácticas y proyectos de MDES. Aquí compartiremos el trabajo del curso y revisaremos las entregas.

## Ejercicios

- [01 · Portfolio personal](EJERCICIOS/01-Portfolio.md)

## Organización

Cada alumno tendrá una carpeta con su nombre y apellidos dentro de `ALUMNOS`, con una subcarpeta por práctica o proyecto:

```text
ALUMNOS/
└── NOMBRE_APELLIDOS/
    ├── PRACTICA_01/
    └── PROYECTO_01/
```

## Entregas

1. Trabaja en una rama propia y añade los archivos dentro de tu carpeta.
2. Abre una **pull request** con el título `Nombre Apellidos — Nombre de la práctica`.
3. Mantenla en **Draft** mientras trabajas y pásala a **Ready for review** cuando esté lista para entregar.
4. Revisa los comentarios del profesor y sube las correcciones a la misma rama.

Modifica únicamente tu carpeta. Los requisitos y plazos de cada entrega se indicarán en clase.
